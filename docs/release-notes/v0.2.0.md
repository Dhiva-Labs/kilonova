Kilonova 0.2.0 adds features that other Monero wallets do not offer, or
offer only on desktop. The plan behind them is in
[docs/ROADMAP.md](https://github.com/Dhiva-Labs/kilonova/blob/main/docs/ROADMAP.md).

**Kilonova has not been audited.** Do not keep more in it than you can afford
to lose. Stagenet and testnet are there to try it without risk.

## New

- **A phone as a cold wallet.** Keep a wallet on a phone that stays offline.
  A watch-only wallet on another device builds transactions; the offline
  phone checks the payments and signs them; every message moves as QR codes.
  The offline phone shows what the transaction itself pays, not what it was
  told.
- **Pair with your own server.** The self-hosting kit in `tools/selfhost`
  runs a pruned node, a light wallet server and Tor, then prints one code.
  Scan it and the wallet uses both.
- **Check your light wallet server.** An opt-in setting confirms every
  payment the server reports against a node, and drops any it invented.
- **Payment requests.** Ask for an amount with a label and an expiry. Each
  request gets its own address and shows when it is paid, with a
  notification if you turned those on.
- **Coin control.** Freeze coins, or send from the ones you pick. Review
  warns when the coins arrived on several of your addresses, because spending
  them together links those addresses.
- **A second opinion on the node.** Full sync compares your node's chain with
  another node's and warns when they differ.
- **Find nodes on your network,** such as a node on your home server.
- **Check a payment.** Enter a transaction ID, its key and an address to see
  what that address received.
- **Copy and paste.** Copy buttons for every address, the transaction ID and
  key, the seed and a new Show keys screen. Copying the seed or a secret key
  asks first and clears the clipboard after 60 seconds. Long fields have a
  paste button.
- The seed screen now shows the restore height, so a restore scans from
  there instead of the start.

## Files

| File | For |
|---|---|
| `kilonova-*-android-arm64-v8a.apk` | Most Android phones |
| `kilonova-*-android-armeabi-v7a.apk` | Older 32-bit Android phones |
| `kilonova-*-android-x86_64.apk` | Android emulators and x86 devices |
| `kilonova_*_amd64.deb` | Debian, Ubuntu and derivatives |
| `kilonova-*-linux-x64.tar.gz` | Other Linux distributions |
| `kilonova-*-windows-x64-setup.exe` | Windows installer |
| `kilonova-*-windows-x64.zip` | Windows without installing |

Check downloads against `SHA256SUMS`. The Android APKs are signed with the
same Kilonova release key as 0.1.0, so they install as an update; its
certificate's SHA-256 fingerprint is
`04:C8:83:64:15:DD:E7:DC:17:D8:E0:F0:C1:17:86:0A:2A:59:3D:31:C3:DC:D4:B5:30:83:12:40:EC:46:BF:34`
(`apksigner verify --print-certs <apk>`). The Windows files are not code-signed
yet, so Windows SmartScreen will warn before running them.

## Known limits

- No hardware wallets or multisig yet.
- Background sync is Android only; desktops sync while the app is open.
- Light wallet servers see your incoming payments; full sync avoids that.
