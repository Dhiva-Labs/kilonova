Kilonova 0.3.0 is about resource use: the same wallet, using far less of
your network, battery, disk and memory. Nothing about what the wallet
checks has changed.

**Kilonova has not been audited.** Do not keep more in it than you can afford
to lose. Stagenet and testnet are there to try it without risk.

## Faster, lighter sync

Measured on a full sync of a 16,000-block test chain:

| | 0.2.0 | 0.3.0 |
|---|---|---|
| Time | 5.8 s | 1.2 s |
| Requests to the node | 17,056 | 493 |
| Downloaded | 23.9 MiB | 3.3 MiB |
| Written to disk | 21.4 MiB | 0.9 MiB |
| One idle minute at the tip: wakeups, disk writes | 143, 1.8 MB | 7, none |

- Blocks arrive in one request. Most nodes leave out a piece of each
  block's data, which made the wallet ask again two or three times per
  block; now only the missing pieces are fetched, in batches. Every
  transaction is still checked against its block.
- One request at the chain tip checks for both new blocks and
  reorganizations, and transactions waiting in the pool are fetched once.
- Connections to your node or server stay open between rounds, so Tor and
  TLS connections are not set up again every 30 seconds.
- The wallet cache is saved only when something changed.
- In the background, a wallet that is caught up looks for new blocks every
  five minutes instead of every 30 seconds, and looks right away when you
  come back. Unreachable nodes are retried less and less often, up to
  every five minutes.

## A lighter app

- Long histories and coin lists build only the rows on screen. A wallet
  with 2,000 transactions opens its page in about a tenth of the time and
  memory it took before.
- The wallet page reloads its data when a block arrives or a sync round
  ends, not on every progress update.
- The library that holds the Rust core is a third smaller (12.9 MB to
  8.7 MB on Linux).

## Files

| File | For |
|---|---|
| `kilonova-*-android-arm64-v8a.apk` | Most Android phones |
| `kilonova-*-android-armeabi-v7a.apk` | Older 32-bit Android phones |
| `kilonova-*-android-x86_64.apk` | Android emulators and x86 devices |
| `kilonova_*_amd64.deb` | Debian, Ubuntu and derivatives |
| `kilonova-*-linux-x64.tar.gz` | Other Linux distributions |
| `kilonova-*-windows-x64-setup.exe` | Windows installer |
| `kilonova-*-windows-x64.zip` | Windows without installing |

Check downloads against `SHA256SUMS`. The Android APKs are signed with the
same Kilonova release key as earlier versions, so they install as an update;
its certificate's SHA-256 fingerprint is
`04:C8:83:64:15:DD:E7:DC:17:D8:E0:F0:C1:17:86:0A:2A:59:3D:31:C3:DC:D4:B5:30:83:12:40:EC:46:BF:34`
(`apksigner verify --print-certs <apk>`). The Windows files are not code-signed
yet, so Windows SmartScreen will warn before running them.

## Known limits

- No hardware wallets or multisig yet.
- Background sync is Android only; desktops sync while the app is open.
- Light wallet servers see your incoming payments; full sync avoids that.
