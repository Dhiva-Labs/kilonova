Kilonova 0.4.0 adds backups, payment notifications from your own server,
opt-in checks for payments while the app is closed, and more privacy on
the network.

**Kilonova has not been audited.** Do not keep more in it than you can afford
to lose. Stagenet and testnet are there to try it without risk.

## New

- **Backups.** Settings, Your data, Backup saves the wallets you choose to
  one file: wallet files exactly as stored, sync caches, labels, address
  book, notes, payment requests and node settings. The file is encrypted
  with its own passphrase (at least 12 characters), separate from your
  wallet passwords. Restoring never overwrites anything; a wallet that
  already exists comes back as "Name (restored)". Your seed is still the
  backup of your funds; this one also keeps everything else.
- **Checks for payments while the app is closed (Android, opt-in).** Off
  until you turn it on under Settings, Background. Kilonova explains what
  it does, asks for the notification permission and for the password of
  each wallet you choose. About every 15 minutes, without opening the app
  or unlocking anything, it checks those wallets and tells you when a
  payment arrives. To do that it keeps each chosen wallet's view key on the
  phone, locked by the phone's secure hardware; the view key can see
  incoming payments but cannot spend. Your seed and spend key never leave
  the password-protected wallet file. Turning it off deletes what it kept.
- **Payment notifications from your own server.** The self-hosting kit can
  tell your phone the moment a payment reaches a wallet, through Tor and
  UnifiedPush (for example the ntfy app). The message says only that
  something arrived: no amount, address or transaction. Nothing goes
  through Google or anyone else's server. See `tools/selfhost/README.md`.
- **Keep syncing in the tray (Linux and Windows).** Closing the window can
  keep unlocked wallets syncing from the system tray, behind the same kind
  of consent screen. Off by default.

## More private on the network

- **A Tor circuit per wallet.** With Tor, each wallet, and each kind of
  request within it, uses its own circuit, so nodes cannot link your
  wallets by exit address.
- **Payments go out through a different node.** With a proxy set, a
  signed transaction is sent through a random public node instead of the
  one you sync from, so that node does not see you send. If it does not
  answer, Kilonova uses your sync node and tells you.
- **Cover lookups.** Checking a transaction (payment proofs, and checking a
  light wallet server's payments against a node) asks for it among seven
  real transactions from nearby blocks, so the node cannot tell which one
  you care about. Because of that, checking a light wallet server's
  payments against a node is now on by default.

## Changed

- Android's old background sync, which kept unlocked wallets running
  behind an always-on notification, is replaced by the checks above.
  Leaving the app locks your wallets again. The update turns the old
  setting off, on desktops too; turn the new one on if you want it.

## Files

| File | For |
|---|---|
| `kilonova-*-android-arm64-v8a.apk` | Most Android phones |
| `kilonova-*-android-armeabi-v7a.apk` | Older 32-bit Android phones |
| `kilonova-*-android-x86_64.apk` | Android emulators and x86 devices |
| `kilonova_*_amd64.deb` | Debian, Ubuntu and derivatives |
| `kilonova-*-linux-x64.tar.gz` | Other Linux distributions |
| `kilonova-*-windows-x64-setup.exe` | Windows installer |
| `kilonova-*-windows-x64.zip` | Windows without installing |

Check downloads against `SHA256SUMS`. The Android APKs are signed with the
same Kilonova release key as earlier versions, so they install as an update;
its certificate's SHA-256 fingerprint is
`04:C8:83:64:15:DD:E7:DC:17:D8:E0:F0:C1:17:86:0A:2A:59:3D:31:C3:DC:D4:B5:30:83:12:40:EC:46:BF:34`
(`apksigner verify --print-certs <apk>`). The Windows files are not code-signed
yet, so Windows SmartScreen will warn before running them.

## Known limits

- No hardware wallets or multisig yet.
- Checks while the app is closed are Android only; on desktops, Kilonova
  checks while it runs, including from the tray.
- Light wallet servers see your incoming payments; full sync avoids that.
