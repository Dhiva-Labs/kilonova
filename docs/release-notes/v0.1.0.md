First release of Kilonova, an open-source Monero wallet for Linux, Windows and
Android.

**Kilonova has not been audited.** Do not keep more in it than you can afford
to lose. Stagenet and testnet are there to try it without risk.

## What it does

- Several wallets on mainnet, stagenet and testnet; create or restore from a
  25-word or Polyseed seed, a spend key, or as view-only.
- Full sync: scans blocks on your device from a node you choose (community
  nodes are bundled; add your own). Payments waiting in the pool show at once.
- Light wallet server sync, with your own monero-lws or a provider you trust.
  The view key is shared only after you agree for that exact server, and
  every output it reports is checked with your keys, including its amount.
- Send to several recipients or send everything, with fee priorities.
  Review shows what the signed transaction pays before the password (or
  fingerprint) publishes it.
- Receive with QR codes and amount requests; scan QR codes with the camera on
  Android or from an image on desktop.
- Address book, transaction notes and payment proofs (transaction keys that
  monero-wallet-rpc's `check_tx_key` accepts).
- Tor or any SOCKS5 proxy for all traffic, onion nodes, and pinned
  certificates for your own node.
- Optional, off by default: prices in your currency, payment notifications,
  and background sync on Android.

## Files

| File | For |
|---|---|
| `kilonova-*-android-arm64-v8a.apk` | Most Android phones |
| `kilonova-*-android-armeabi-v7a.apk` | Older 32-bit Android phones |
| `kilonova-*-android-x86_64.apk` | Android emulators and x86 devices |
| `kilonova_*_amd64.deb` | Debian, Ubuntu and derivatives |
| `kilonova-*-linux-x64.tar.gz` | Other Linux distributions |
| `kilonova-*-windows-x64-setup.exe` | Windows installer |
| `kilonova-*-windows-x64.zip` | Windows without installing |

Check downloads against `SHA256SUMS`. The Windows files are not code-signed
yet, so Windows SmartScreen will warn before running them.

## Known limits

- No hardware wallets or multisig yet.
- Background sync is Android only; desktops sync while the app is open.
- Light wallet servers see your incoming payments; full sync avoids that.
